# Prompt 1A Implementation Plan: Dropdown Synchronization, Typography Normalization, Deck & Flashcard Expansion, Design System Orchestration

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Resolve 5 critical UI/UX and design architecture issues in MindSparks / TinhMinhLaKey without breaking any business logic (IndexedDB, SM-2, KaTeX, AI/LMS Parser) and ensuring 100% test pass rate (`npm test`, `npm run build`).

**Architecture:** 
1. Centralize dropdown open/close control into a single unified controller (`App._toggleCyberDropdownById`) in `js/app.js` and eliminate CSS stacking context conflicts (`z-index: auto` on `.quiz-card > *` + elevation rules).
2. Point font variables (`--font-pixel`, `--font-heading`, etc.) to `--font-body` (`Plus Jakarta Sans` / `Be Vietnam Pro` / `Inter`) to modernize all titles and numbers without breaking existing tests that verify variable names and `@font-face`.
3. Broaden `.decks-grid` (`minmax(340px, 1fr)`) and convert `.deck-actions` to a 2-tier grid with full-width "Ôn tập" on top and 4 auxiliary buttons on bottom.
4. Expand desktop flashcard stage (`380px` height, `820px` width) and font sizes (`clamp(1.22rem, 2.1vw, 1.5rem)`), while keeping static base height for test backward compatibility.
5. Extend `css/theme.css` with Section 13 orchestration tokens and establish `DESIGN.md` as the master single source of truth.

**Tech Stack:** Vanilla JS (ES6+), CSS3 (Custom Properties, Grid, Flexbox, Stacking Context), Offline PWA, Node test runner with Chrome CDP.

**Spec:** `docs/promt/promt1a.md`
